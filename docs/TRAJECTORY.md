# Jerk-limited профиль движения (S-curve)

Путь робота — полилиния из ≤ 8 точек (в демо: сегмент `tcp → target`).
Профиль скорости строится по длине дуги `D` при лимитах `vmax, amax, jmax`.
Реализация — аналитическая, без итерационных решателей: 7 сегментов,
времена которых определяются замкнутыми формулами.

## Структура профиля

```text
[jerk +T1][acc const T2][jerk −T1][cruise Tc][jerk −T1][decel const T2][jerk +T1]
```

Торможение — точное зеркало разгона; краевые условия `v(0)=v(T)=0`,
`a(0)=a(T)=0`. Интегрирование каждого сегмента:

```text
v(τ) = v0 + a0·τ + j·τ²/2
s(τ) = s0 + v0·τ + a0·τ²/2 + j·τ³/6
```

Таблица из 7 записей `{T, j, a0, v0, s0}` — `std::array`, без аллокаций.

## Ветки построения

Пусть `t1 = amax / jmax` — время выхода на `amax` чистым рывком.

### 1. Cruise-профиль (vmax достижим)

Разгон до `vmax` занимает путь `s_ramp`; если `2·s_ramp ≤ D`, в середине
есть фаза постоянной скорости `Tc = (D − 2·s_ramp) / vmax`.

Два подслучая разгона:

- `vmax ≤ amax²/jmax` — ускорение не успевает дорасти до `amax`:
  `T1c = √(vmax/jmax)`, `T2c = 0`, `s_ramp = jmax·T1c³`;
- иначе — классика: `T1c = t1`, `T2c = (vmax − jmax·t1²)/amax`,
  `s_ramp = v1·(T1c+T2c) + amax·(T1c²/2 + T1c·T2c + T2c²/2)`,
  где `v1 = jmax·t1²/2`.

### 2. Промежуточный (cruise нет, `D ≥ 2·jmax·t1³`)

Разгон идёт на полную `amax` (`T1 = t1`), но растояния не хватает на cruise.
`T2 ≥ 0` находится из квадратного уравнения `s_ramp(T2) = D/2`:

```text
(amax/2)·T2² + (v1 + amax·t1)·T2 + (v1·t1 + amax·t1²/2 − D/2) = 0
```

`v_peak = jmax·t1² + amax·T2 < vmax` автоматически: корень лежит в области
`T2 < t2_vmax` по монотонности `s_ramp(T2)`.

### 3. Треугольный (`D < 2·jmax·t1³`)

Рывковые фазы короче `t1`: `T1 = cbrt(D / (2·jmax))`, `T2 = Tc = 0`,
`v_peak = jmax·T1² < amax²/jmax ≤ …` — лимиты соблюдены автоматически.

Ветка 3 покрывает и случай `vmax < amax²/jmax` при малом `D`: условие
`2·jmax·t1³` проверяется после ветки 1, и для таких `vmax` cruise-подветка
уже обработала большой путь.

## Инварианты (проверяются тестом на 4 конфигурациях лимитов)

| Инвариант | Смысл |
|---|---|
| `pos(T_total) = D` | доезжает ровно в цель (±1e-9) |
| `vel(T_total) = 0` | останавливается в цели |
| `vel(t) ≤ vmax`, `|acc(t)| ≤ amax`, `|jerk| ≤ jmax` ∀t | лимиты не нарушены ни в одной ветке |
| `pos(t)` монотонна | корректна инверсия |

## Инверсия времени

`time_at(s)` — время достижения длины дуги `s`: бисекция по монотонному
`pos(t)`, ровно 32 шага. Почему бисекция, а не Ньютона: детерминизм
(одинаковые биты результата на любой машине), отсутствие аллокаций,
верхняя граница стоимости 32·O(7).

## Тестирование

Модульный тест строит профили во всех трёх ветках (cruise, промежуточный,
треугольный, плюс низкий `vmax` с jerk-only разгоном) и для каждого
проверяет таблицу инвариантов по сетке времени с шагом `T_total/200` —
детерминированно, без аллокаций.
