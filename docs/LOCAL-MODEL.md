# Как это написано локальной моделью

## Тезис

Проект создан **без единого обращения в облако**: код, сборка, отладка,
тесты и документация — замкнутый контур на обычном рабочем месте.
Это ответ на два скепсиса сразу: «ИИ-код не живёт в промышленной глубине»
и «локальная модель не тянет системный уровень».

## Стенд

| Компонент | Значение |
|---|---|
| Модель | **Strata** — семейство локальных моделей (квантованный Qwen, IQ3), сессия в агентском терминале |
| GPU | NVIDIA GeForce RTX 3090, 24 ГБ — inference целиком в VRAM, квантование IQ3 |
| CPU / RAM | Xeon E5-2699 v3 (2015 г.), 64 ГБ — сервер среднего, не флагманского класса |
| Сеть | не использовалась: компилятор, санитайзеры, Python — локально |

Железо не самое дорогое: рабочая станция на потребительской RTX 3090 и серверном Xeon
прошлого поколения. Никаких H100, никакой облачной инференс-архитектуры.

## Цикл, в котором код дожил до PASS

Генерация без верификации дала правдоподобный код с четырьмя скрытыми
дефектами (см. VERIFICATION.md). Спас агентский цикл:

```text
генерация (модель)
   → компиляция −Werror (мгновенный фильтр синтаксиса/типов)
   → модульные тесты + инварианты (ловят математику)
   → ASan/UBSan (ловят память/UB)
   → TSan (ловит гонки)
   → Python-оракул: алгоритм портируется на второй язык и сверяется
     формула-в-формулу (именно так найден знак в OBB slab)
   → бухгалтерия событий: planned+rejected == ok (ловит конфигурацию)
   → правка → повтор
```

Важно: модель не «угадывала правильную версию с первого раза». Она
корректно и быстро чинила то, что обнаруживала верификация, — то есть
работала как инженер с тестами, а не как генератор текста.

## Что показал эксперимент

1. **Локальная модель тянет объём**: ~1300 строк C++20 (протокол, геометрия,
   профили, планировщик, SPSC, тесты) — с нуля, за один рабочий заход.
2. **Слабое место — не язык, а скрытые предположения**: знак в формуле,
   вырожденная ветка решателя, несуществующий id робота, молчаливый дефолт
   стартовой позиции. Это ровно тот класс брака, который на заводах ловит
   нормоконтроль и приёмка.
3. **Верификация — мультипликатор**: без санитайзеров и оракула код «компилировался
   и почти работал». Требования к приёмке (матрица PASS/FAIL) превращают
   болтовню в проверяемый факт — та же логика, что с НСИ в АСКОН-контуре:
   автоматизация работает ровно настолько, насколько нормализованы данные
   и критерии.

## Воспроизведение

Полный цикл — три команды:

```bash
make run          # ≈ 10 секунд с компиляцией, тесты ≈ 0.04 с каждый
```

Никаких внешних сервисов, никакой настройки, кроме g++ 13.
